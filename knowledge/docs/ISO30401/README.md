## ISO 30401 是什麼

ISO 30401:2018 是關於 **knowledge management systems（KMS）** 的管理系統標準。它設定要求並提供指引，用於建立、實施、維護、審查與改善組織中的有效知識管理系統。

公開摘要指出，ISO 30401 適用於任何組織，不受組織類型、規模、產品或服務限制。

它的目的不是規定某一套知識管理工具，而是提供一套管理系統框架，協助組織：

- 透過知識創造價值。
- 降低關鍵知識流失風險。
- 支援決策、學習、協作與持續改善。
- 將知識管理和組織目標、流程、文化與治理連接起來。
- 作為內部稽核、外部評估、認證或成熟度檢查的基礎。

## 適用對象

ISO 30401 適用於需要系統化管理組織知識的人與團隊，例如：

- Knowledge managers / CKO / KM team。
- HR、Learning & Development、training teams。
- 專案經理與營運管理者。
- IT / information management teams。
- 高階管理者與 strategy teams。
- 顧問、內部稽核員與外部評估人員。
- 公私部門各類組織。

常見使用情境：

- 建立組織層級 KMS。
- 改善 onboarding、mentoring、succession planning。
- 降低人員流動造成的知識流失。
- 標準化跨地區或跨團隊最佳實務。
- 支援跨組織協作與共同目標。
- 將知識管理納入品質、資訊安全、人才管理或營運治理。

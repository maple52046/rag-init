## 這份 style guide 的定位

Google Developer Documentation Style Guide 提供面向 software developers 與 technical practitioners 的技術文件編輯準則，目標是讓文件清楚、一致且適合技術讀者。

若是第一次使用，來源頁建議先從這三個主題開始：

- [Highlights](https://developers.google.com/style/highlights)
- [Voice and tone](https://developers.google.com/style/tone)
- [Text-formatting summary](https://developers.google.com/style/text-formatting)

若是查特定問題，則把它當 reference 使用，例如查：

- 詞彙與用字。
- 拼字。
- 文字格式。
- 語氣與風格。
- 技術寫作慣例。

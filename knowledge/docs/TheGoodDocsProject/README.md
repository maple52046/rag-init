# The Good Docs Project Core Templates

PURPOSE: 保存 The Good Docs Project（TGDP）Core documentation template pack 的原始模板檔，供撰寫常見技術文件時參考與複用。
APPLIES TO: concept docs, how-to docs, README, reference docs, release notes, tutorials, troubleshooting docs.
關鍵字: The Good Docs Project, TGDP, documentation templates, core documentation template pack, docs-as-code.

> 本目錄下載自 [The Good Docs Project templates](https://gitlab.com/tgdp/templates#how-to-get-the-templates) 的 **Core documentation template pack**。來源 commit：`41645d9cc4b7d80db06d03cd7b862c16ece849b8`。來源 repo 授權見 [`LICENSE`](LICENSE)，原始 README 保存於 [`source-README.md`](source-README.md)。

## 內容

Core documentation template pack 位於 [`core-documentation-template-pack/`](core-documentation-template-pack/)。

包含 7 種核心文件類型：

- [`concept`](core-documentation-template-pack/concept/)：概念、背景、脈絡或產品功能解釋。
- [`how-to`](core-documentation-template-pack/how-to/)：完成單一任務的精簡步驟。
- [`readme`](core-documentation-template-pack/readme/)：專案入口資訊、如何開始使用與如何互動。
- [`reference`](core-documentation-template-pack/reference/)：應用程式元件或特性的描述。
- [`release-notes`](core-documentation-template-pack/release-notes/)：新功能、改善、修 bug 與已知問題。
- [`tutorial`](core-documentation-template-pack/tutorial/)：以 hands-on learning 為目的的範例專案教學。
- [`troubleshooting`](core-documentation-template-pack/troubleshooting/)：常見症狀、原因與解法。

---

## 檔案類型

每個模板目錄可能包含下列檔案類型；並非每個模板都具備全部類型。

- `template_*.md`：可直接複製改寫的原始模板。
- `guide_*.md`：如何填寫模板的說明。
- `resources_*.md`：建立模板時使用或推薦的參考資源。
- `process_*.md`：研究、撰寫、維護該文件類型的流程建議。
- `example_*.md`：模板使用範例。

---

## 使用方式

使用時建議：

1. 先選擇對應的文件類型目錄。
2. 先讀 `guide_*.md` 或 `process_*.md`。
3. 複製 `template_*.md` 到實際文件位置後再填寫。
4. 若專案已有更具體的寫作規範，優先遵守專案規範。

## Zettelkasten 是什麼

Zettelkasten 是一套用來學習、思考與產出知識的筆記系統。它的目標不是收藏資訊，而是讓使用者把閱讀、理解、詮釋、連結與寫作整合成長期可演化的工作流程。

Zettelkasten 的產出通常是文字：文章、研究、文件、書稿、論述或其他可分享的知識成果。

它關心三個面向：

- **Knowledge Management**：如何有效學習、整理與維護知識。
- **Writing**：如何把長期累積的筆記轉化成可發表文字。
- **Reading**：如何取得新材料、處理來源並轉成自己的理解。

---

## 核心觀念

Zettelkasten 的重點不是工具，而是流程與原則：

- 只收藏資料不會增加知識；必須解讀來源、形成自己的想法並放入筆記網路。
- 每則 Zettel 應聚焦於單一想法，並可被其他筆記引用。
- 連結比單靠全文搜尋更重要，因為連結保留了想法之間的脈絡與方向。
- 分類不應過早僵化；標籤、連結與結構筆記更適合支撐長期成長。
- 寫作不是最後一步，而是整個系統的自然輸出。
